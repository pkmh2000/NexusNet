# 人際關係網絡管理系統 (NexusNet PWA)

打造一套支援 Android、iOS、平板與桌面全平台的現代人際脈絡管理系統（PWA），以個人或核心節點為中心，透過互動式力導向蜘蛛網與同心圓層級雙重視圖，視覺化呈現複雜社交脈絡；同時提供彈性自訂動態欄位（含國曆/農曆生日換算）、節點拖曳連線與切斷、標籤分組、即時搜尋，以及本地加密自動備份與匯出還原功能。

---

### User Review & Critical Decisions

> [!IMPORTANT]
> 依據前期需求溝通，本系統已確認以下關鍵產品與技術決策，請檢視確認：

- **確認決策 1（定位與部署）**：採用標準 **PWA (Progressive Web App)** 漸進式應用架構，桌機、Android、iOS 皆可一鍵安裝至桌面或主畫面，離線亦可流暢操作，具備本機資料庫與 AES 加密 JSON 備份機制，免除複雜實體主機維護與手動 SSL 申請負擔。
- **確認決策 2（網絡視覺化）**：提供 **混合雙重視圖**：
  1. *蜘蛛網力導向圖 (Force-Directed Graph)*：支援自由拖曳節點、彈力佈局、物理碰撞模擬、多層交錯關係連線與拖曳拉線連接/切斷。
  2. *同心圓層級視圖 (Concentric Radar View)*：點選任一成員後以其為核心圓心，依一度關係、二度關係、三度關係由內而外環狀展開。
- **確認決策 3（個人資訊自訂欄位）**：採用 **完全自訂 Schema 引擎**，使用者可自由新增/刪除欄位與定義欄位型態（文字、電話、電子郵件、國曆生日、農曆生日、多行經歷、下拉選擇、標籤），並支援自動換算生肖、天干地支與每年生日提醒。

### 1. Overview & Core Concept

- **What It Does**: 提供直覺的人際網絡圖譜與聯絡人資料庫。使用者可建立個人及所有關係人單元，透過畫布直接拖曳節點調整物理位置、以滑鼠或手指拉出連線建立多對多關係標籤，或點選連線進行切斷；支援聚焦任一人物查看其專屬子網脈絡。
- **Target Audience / Persona**: 重視深度人脈經營的專業商務人士、跨領域創業者、家族譜系管理者、社群策展人以及需要梳理複雜關係鏈的個人使用者。
- **Key Value**: 擺脫傳統電話簿單調的平面列表，讓錯綜複雜的親友、職場、業務合作夥伴與二度介紹關係一目了然，並給予每位聯絡人完全客製化的資料結構與隱私保護。

### 2. User Experience & Visual Design

#### A. Key User Flows
1. **導覽與畫布瀏覽 (Explore Flow)**:
   - 進入主畫面即顯示中心節點（「我」）與周圍一級、二級關係網絡。
   - 支援滑鼠滾輪/手勢雙指縮放 (Zoom)、畫布平移 (Pan)、節點拖曳 (Drag)。
   - 點擊畫布任意節點，即時在右側（或手機底部抽屜 Sheet）滑出「成員詳情單元」，並可一鍵切換「以他為中心聚焦關係網」。
2. **新增/編輯成員與自訂欄位 (Profile & Custom Field Flow)**:
   - 點擊「新增成員」，填寫基本資訊（姓名、頭像/顏色、關係簡稱）。
   - 在「動態欄位」區塊可隨意點擊「+ 新增欄位」，設定自訂名稱（如：公司、高中社團、喜好）與型態（文字、電話、國曆日期、農曆生肖月日）。
   - 輸入農曆日期時，系統自動換算對應國曆日期與天干地支生肖；輸入電話/信箱支援點擊直接撥號或發信。
3. **建立與切斷人際連線 (Connect / Disconnect Flow)**:
   - 點擊工具列「連線模式」，點選起點節點並拖曳指標至目標節點放開，即彈出連線屬性設定（關係類型：親戚/同事/摯友/商業夥伴，可自訂新建標籤、設定關係強度與方向性）。
   - 點擊既有連線，可查看關係標籤、編輯備註或點擊「切斷連線」。
4. **備份與資料管理 (Backup & Safe Management Flow)**:
   - 提供直觀的資源與資料儀表板，顯示總人數、連線數、獨立群落數與最近修改時間。
   - 支援「一鍵本地加密備份（下載 .json 檔）」、「匯入還原」，以及「自動定期快照儲存於瀏覽器 IndexedDB/LocalStorage」。
5. **跨平台安裝 (PWA Install Flow)**:
   - 頂部導航列常駐「安裝 App」按鈕（或 iOS 操作引導），點擊可免應用程式商店即刻安裝至手機或電腦桌面。

#### B. Visual Identity & Theme
- **風格基調 (Aesthetic)**: 現代精密儀表與沉浸式圖譜視覺（深色深邃星系 / 淺色石板紙質，支援一鍵深淺色主題切換）。
- **色彩系統 (60-30-10 Palette)**:
  - 60% 畫布基底: 深色背景 `#0B0F17` (Deep Space Slate) / 淺色背景 `#F8FAFC`。
  - 30% 結構表面: 卡片與側欄 `#131B2E` / 淺色 `#FFFFFF`，帶極細 1px 邊框 (`border-slate-800` / `border-slate-200`)。
  - 10% 強調色彩: 科技藍金屬色 `#3B82F6` (Primary) 與 琥珀金 `#F59E0B` (中心節點光暈與特殊高亮)。
- **字體規範**:
  - 標題與品牌: `Plus Jakarta Sans` / 繁體中文無襯線系統字體，確保清晰俐落。
  - 數值與關係統計: `JetBrains Mono` / `tabular-nums`，數字對齊無抖動。
  - 零藥丸標籤規範 (Zero-Pill): 靜態文字資訊以優雅的微間距與 `·` 間隔，互動過濾與選鈕則採具回饋的段落控制切換鈕。

### 3. Key Product Decisions & Trade-Offs

- **決策 1：混合圖形繪製引擎（HTML5 Canvas + React 物理力導向引擎）**
  - *採納做法*: 使用高性能 HTML5 2D Canvas 搭配 Verlet/Coulomb 斥力引力物理模擬算法處理核心圖譜渲染，UI 覆蓋層（面板、自訂欄位表單、搜尋過濾）使用 React DOM。
  - *原因*: SVG 在大量節點（超過 200 個）時 DOM 節點過重容易引起掉幀；Canvas 具備極致 60fps 幀率與流暢縮放平移體驗，手機端觸控亦極為順暢。
- **決策 2：無伺服器依賴的本機優先資料架構 (Local-First Architecture)**
  - *採納做法*: 資料以結構化 JSON 存放於瀏覽器 IndexedDB / LocalStorage，具備完整匯出備份、加密金鑰保護與快照歷史。
  - *原因*: 人際關係屬於高敏感個人隱私資料，本機儲存完全保證隱私安全、無外洩風險，且無須負擔外部雲端伺服器維護費。
- **決策 3：彈性動態 Schema 與農曆換算演算法**
  - *採納做法*: 每位聯絡人的欄位列表為陣列式動態定義 `{ id, key, label, type, value }`，內建萬年曆對照表進行國曆與農曆相互推算，並可將欄位標籤作為全域過濾維度。

#### 資料結構設計 (Schema)
1. **Member (成員節點)**:
   - `id`: string (唯一碼)
   - `name`: string (姓名)
   - `avatarColor`: string
   - `isCenter`: boolean (是否為「我」或目前焦點)
   - `group`: string (預設分類：家人/朋友/職場/社群)
   - `customFields`: Array<{ id: string, name: string, type: 'text'|'phone'|'email'|'solar_date'|'lunar_date'|'tags', value: string }>
   - `notes`: string
   - `updatedAt`: number
2. **Relationship (關係連線)**:
   - `id`: string
   - `source`: string (Member ID)
   - `target`: string (Member ID)
   - `label`: string (如：夫妻、父子、同事、合夥人、介紹人)
   - `category`: string (親友/商業/社交/學緣)
   - `strength`: number (1~5，關係緊密程度，影響力導向距離)
   - `bidirectional`: boolean
